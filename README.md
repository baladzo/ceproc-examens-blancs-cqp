CEPROC - Examens blancs CQP pizzaïolo

Site public d’entraînement au CQP pizzaïolo, proposé au CEPROC pour validation pédagogique. Dix sujets différents, photos, PDF remplissables et corrections. Feuilles de cours : 18 chapitres pour les 170 questions, avec fiches PDF et livret complet. Ouvrir index.html pour les exercices et cours.html pour les cours. Le suivi automatique est préparé mais désactivé ; Firebase et les autorisations serveur restent à configurer et vérifier. admin.html donne l’état du suivi. Aucune invitation ni aucun e-mail n’est envoyé par la publication de ce site.
